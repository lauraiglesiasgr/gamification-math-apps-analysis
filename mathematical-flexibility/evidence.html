Evidence and verification

This case study presents aggregate results documented in the 2026 thesis. Questionnaire summaries were checked against its paired-score table during preparation of the portfolio. The original JASP project is unavailable: inferential results are attributed to the thesis and are not presented as an independently reproduced analysis.

The portfolio includes session-level strategy-origin counts as reported. Criterion-level ratings and assessment rubrics are not distributed because the criterion lists in the methods summary and appendix differ.

Statistical reporting

The source reports W = 0, p = 0.001 (two-sided), z = 3.18 and r = 0.58. It explicitly defines r = z / sqrt(N), with N = 30. That arithmetic gives about 0.581.

Some paired-test implementations use the number of pairs instead. The rstatix documentation specifies that convention. Using the same reported z with 15 pairs would give approximately 0.821; excluding the two zero-difference pairs from the denominator would produce another value. These are denominator illustrations, not replacement effect estimates.

Accordingly, the portfolio does not label r = 0.58 as an independently replicated result or promote it as a headline effectiveness claim. Because the original JASP project is unavailable, its calculation settings, tie handling and any continuity correction could not be verified. A normal approximation and a conditional exact calculation need not yield the same p-value.

The private audit reconstructed paired scores from Table 4.3 to check descriptive summaries. That is a new verification activity performed for this adaptation, not analysis code recovered from the original research. No paired records are included in the portfolio files.

What can be regenerated?

Included: a Python standard-library script that reads transcribed aggregate CSV files, checks totals and creates three SVG figures. This is figure-generation reproducibility.

Not included: the original participant dataset, JASP project, item-level questionnaires, criterion-level ratings, coding files or field notes. The original statistical and qualitative analyses cannot be fully replicated from this repository.

The aggregate inputs are real thesis summaries, not synthetic pupil data. No synthetic dataset is used.

Data shared in this portfolio

Only whole-sample summaries, newly drawn figures and game-rule illustrations are included. The source PDF, participant records, school identity, diagnostic information, pupil quotations, photographs and signed documentation are not distributed.
